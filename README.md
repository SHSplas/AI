# AI Project

This is my AI project for **Beest (Hack Club)**.

Honestly, during building this I ended up making a bunch of different modules, tools, and random experiments. Instead of deleting stuff that might still be useful later, I just kept everything here and tried to explain what it does.

So yeah — this repo is a mix of finished stuff, half-finished stuff, and testing ideas.

##  What this is

This project includes:
- AI-related modules I built while learning/experimenting
- Small tools and helper scripts
- Random prototypes I tested out
- Notes + comments so you can actually understand what’s going on

It’s more of a “build log” than a polished final product.

## How it’s built

Some parts are solid, some parts are experimental, and some are just me trying things out.

I tried to keep the code readable with comments so it doesn’t turn into a mess.
